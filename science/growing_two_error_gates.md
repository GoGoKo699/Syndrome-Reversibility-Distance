# Optimal two-error gates at growing distance

The [twenty-five-qubit result](two_error_gates.md) extends to every concatenation depth $m\ge2$. The required change is a correlated choice of the inner block carrying a stabilizer-padding term. Uniform padding among all inactive blocks works at depth two but loses the higher-level pair correlations. Padding through the inactive frontier of the logical-support tree preserves them.

For each logical Pauli axis on the concatenated five-qubit code, the construction attains

```math
\boxed{
n=5^m,\quad d=3^m,\quad t=2,\quad
\ell=d+4,\quad
J=J_*(d)\omega,\quad
J_*(d)=\frac{4d^2+21d+8}{8},\quad r_S=\infty.
}
```

Both interaction order and the native coupling budget at that order are optimal for this code family. The coupling lower bound permits arbitrary physical Hamiltonians satisfying the fixed-code transparency model, not only the four classes used in the construction. The theorem protects physical Pauli errors of weight at most two; the number of protected faults does not grow with the code distance.

| Concatenation depth | Physical qubits | Distance | Minimum interaction order for this guarantee | Exact coupling optimum at that order |
|---:|---:|---:|---:|---:|
| 2 | 25 | 9 | 13 | $521/8$ |
| 3 | 125 | 27 | 31 | $3491/8$ |
| 4 | 625 | 81 | 85 | $27953/8$ |

The code family, signed five-qubit cosets and syndrome reversibility property are inherited ingredients described in the [single-error family](minimum_readout_safe_gates.md). The result here is the two-error extension, its frontier-padding rule, and the exact block-resolved resource formula.

## 1. Bottom blocks and the logical-support tree

Partition the physical qubits into

```math
B=5^{m-1}
```

bottom blocks, each containing five qubits. Encoding one outer logical qubit into the depth-$(m-1)$ code and then encoding every outer physical qubit into a five-qubit block gives the same depth-$m$ code. Put

```math
L=m-1,\qquad k=3^L=d/3,\qquad p=k/B.
```

A minimum-weight logical representative on the outer depth-$L$ code has exactly $k$ active bottom blocks. Its support is generated by a rooted tree: at each active internal node choose a signed weight-three representative of the appropriate logical axis from the ten minimum representatives of the five-qubit code. The chosen representative activates three of the five child nodes. Continue to depth $L$.

Choose the ten representatives uniformly at each active internal node. At every internal depth $0\le r<L$ there are exactly $3^r$ active nodes, and the active bottom set $S$ has size $k$. There are

```math
1+3+\cdots+3^{L-1}=\frac{k-1}{2}
```

active internal nodes in total. The two inactive children of each such node root disjoint inactive subtrees. Together these $k-1$ frontier subtrees partition the inactive bottom blocks. The subtrees can have different numbers of bottom blocks.

Each bottom block is active with probability $p=k/B$. Conditional on being active, its logical label is uniform over $X,Y,Z$. This follows from the base fact that each local nonidentity axis occurs twice among the ten minimum representatives at any chosen site; it is independent of the parent's logical axis.

For a bottom block with logical label $\beta$, use the signed normalized sums $G_{3,\beta}$ and $G_{5,\beta}$ of its ten weight-three and six weight-five positive logical representatives. For an inactive block use physical identity, or the signed nonidentity stabilizer average

```math
K_4=\frac{16P_5-I}{15}.
```

Every constituent word retains its actual Hermitian sign. Thus each tensor word constructed below acts as the prescribed positive full-code logical Pauli $\alpha$.

## 2. Four classes and the frontier-padding rule

Use the same four physical patterns as in the depth-two result:

| Class | Active bottom-block factors | Additional inactive factor | Total physical weight |
|---|---|---|---:|
| $A_0$ | $G_3$ in all $k$ active blocks | None | $d$ |
| $A_1$ | Promote one uniformly chosen active block to $G_5$ | None | $d+2$ |
| $A_2$ | Promote a uniformly chosen unordered pair of active blocks to $G_5$ | None | $d+4$ |
| $F$ | $G_3$ in all active blocks | $K_4$ at a frontier-selected inactive block | $d+4$ |

All averages include the random signed outer minimum representative, its sign, and the indicated normalized inner sums. Each class has coefficient mass one in positive logical-coset coordinates, acts as $\alpha$ on the code, and has absolute native Pauli coefficient sum one.

For the fourth class, select the padding block as follows:

1. Choose uniformly one of the $(k-1)/2$ active internal nodes.
2. Choose uniformly one of that node's two inactive children.
3. Choose uniformly a bottom block within that inactive child's subtree, and place $K_4$ there.

Equivalently, choose uniformly one of the $k-1$ inactive frontier subtrees, then choose a bottom block uniformly within it. This choice is correlated with the active support tree. It is not uniform over inactive bottom blocks for a fixed tree. Nevertheless every specified bottom block is selected with the same unconditional probability $1/B$.

At depth two the frontier consists of the two inactive bottom blocks, so $F$ is exactly the stabilizer-padding class $B$ in the [twenty-five-qubit construction](two_error_gates.md). At greater depth the frontier rule is the additional ingredient.

## 3. The pair-correlation identity

Let $i,j$ be distinct specified bottom blocks and define

```math
\rho_{ij}=\Pr(i,j\in S),\qquad
\eta_{ij}=\Pr(\text{padding block is }i,\ j\in S).
```

The frontier rule gives the exact identity

```math
\boxed{\eta_{ij}=\frac{\rho_{ij}}{k-1}.}
\qquad\text{(G1)}
```

### Counting by the first divergence

Let the two leaves share $r$ initial tree edges and diverge at the next edge, with $0\le r<L$. Set $q=3/5$. Choosing three children out of five gives probability $q$ for one specified child and $3/10$ for two specified children, so

```math
\rho_{ij}=q^r\frac3{10}q^{2(L-r-1)}.
\qquad\text{(G2)}
```

The probability that the selected padding node lies at depth $s$ is

```math
w_s=\frac{2\cdot3^s}{k-1},\qquad 0\le s<L.
```

Conditional on this depth, the selected node is uniform among the $3^s$ active nodes. If $s<r$, padding $i$ makes the common branch inactive, so $j$ cannot be active. If $s=r$, the two specified child branches must be inactive and active respectively; the choice of the inactive child gives

```math
\frac{\Pr(\text{padding }i,\ j\in S\mid s=r)}{\rho_{ij}}
=\frac3{2k}.
```

If $s>r$, the two branches at the divergence must both be active. Counting the remaining active path to the selected node, its uniform selection, and the bottom-block choice inside its inactive child gives

```math
\frac{\Pr(\text{padding }i,\ j\in S\mid s)}{\rho_{ij}}
=\frac1k.
```

Therefore

```math
\frac{\eta_{ij}}{\rho_{ij}}
=\frac1k\left(\frac32w_r+\sum_{s=r+1}^{L-1}w_s\right)
=\frac1k\left(
\frac{3^{r+1}}{k-1}
+\frac{k-3^{r+1}}{k-1}\right)
=\frac1{k-1},
```

proving (G1). This calculation also gives the same identity with $i,j$ exchanged. In particular, it does not require the minimum-support ensemble to be a two-design over arbitrary bottom-block subsets.

The unconditional padding probability follows directly as well. For fixed $i$, summing (G1) over $j\ne i$ gives $k\Pr(\text{padding }i)=\sum_{j\ne i}\rho_{ij}/(k-1)=p$, because every active set has size $k$ and excludes its padding block. Thus $\Pr(\text{padding }i)=p/k=1/B$.

### Why uniform inactive-block padding fails

If instead a padding block is selected uniformly among the $B-k$ inactive bottom blocks of a chosen tree, then

```math
\eta_{ij}=\frac{p-\rho_{ij}}{B-k}.
```

The two-error cancellation below would require $\rho_{ij}=k(k-1)/[B(B-1)]$ for every distinct pair. Minimum logical supports at depth greater than one have pair probabilities depending on their first-divergence depth, so that equality generally fails. The frontier rule supplies exactly the missing correlation.

## 4. Exact responses and strict transparency

For a single physical error in a bottom block, the normalized $G_3$, $G_5$ and $K_4$ responses are

```math
r=\frac15,\qquad s=-\frac13,\qquad h=-\frac1{15}.
```

For two physical errors in the same bottom block, the inner logical-class sign depends on that error. Averaging the active bottom logical label gives the exact responses $-1/15$ for $G_3$ and $1/9$ for $G_5$, while $K_4$ still has response $-1/15$. This is the signed five-qubit identity proved in the [depth-two account](two_error_gates.md#3-exact-responses-to-all-errors-of-weight-at-most-two).

For a normalized class $T$, write its scalar response as $TEV=f_T(E)EV\alpha$. This is a full physical-space identity term by term because every term belongs to the same signed logical coset.

### Zero, one, or two errors in one bottom block

For identity the four responses are one. For one nonidentity physical Pauli, put $f_0=1-4p/5$. The four responses are

```math
\left(f_0,\quad
f_0-\frac{8p}{15k},\quad
f_0-\frac{16p}{15k},\quad
f_0-\frac{16}{15B}\right).
\qquad\text{(G3)}
```

For two errors in one bottom block, put $g_0=1-16p/15$. The responses are

```math
\left(g_0,\quad
g_0+\frac{8p}{45k},\quad
g_0+\frac{16p}{45k},\quad
g_0-\frac{16}{15B}\right).
\qquad\text{(G4)}
```

These formulas use the unconditional padding probability $1/B$ and the uniform one- or two-promotion choice among the $k$ active blocks.

### Errors in distinct bottom blocks

Set $\rho=\rho_{ij}$, $\eta=\eta_{ij}=\eta_{ji}$ and $\Delta=s-r=-8/15$. The responses are

```math
\begin{aligned}
f_{A_0}&=1-\frac85p+\frac{16}{25}\rho,\\
f_{A_1}&=f_{A_0}+\frac\Delta k
\left(2p-\frac85\rho\right),\\
f_{A_2}&=f_{A_0}+\frac{2\Delta}k
\left(2p-\frac85\rho\right)
+\frac{2\Delta^2}{k(k-1)}\rho,\\
f_F&=f_{A_0}-\frac{32}{15B}+\frac{128}{75}\eta.
\end{aligned}
\qquad\text{(G5)}
```

For example, the first formula follows by conditioning on whether zero, one, or both bottom blocks are active. The promotion corrections use the probability $1/k$ for a particular active block and $2/[k(k-1)]$ for a particular pair to be promoted. The padding correction uses the probability $1/B$ for either specified block and the mixed padding/active probability $\eta$.

### The Hamiltonian

Define

```math
\begin{aligned}
a_0&=\frac{(d+2)(d+4)}8,&
a_1&=-\frac{d(d+4)}4,\\
a_2&=\frac{d(2d+9)}{16},&
b&=-\frac{5d}{16},
\end{aligned}
```

and set

```math
\boxed{H_\alpha=a_0A_0+a_1A_1+a_2A_2+bF.}
\qquad\text{(G6)}
```

The masses sum to one and satisfy $a_1+2a_2=d/8=3k/8$. Direct substitution into (G3) and (G4) gives response one. For (G5), substitution simplifies the difference from the desired response to

```math
f_{H_\alpha}(E)-1
=\frac{8k}{5}\left(
\frac{\rho_{ij}}{k-1}
-\frac{\eta_{ij}+\eta_{ji}}2\right)=0
```

by (G1). Hence

```math
\boxed{H_\alpha EV=EV\alpha
\quad\text{for every physical Pauli }E\text{ of weight at most two}.}
```

This includes all error axes and all first-divergence depths, rather than an average over a noise distribution. It proves preservation of the full protected error images. Pointwise transparency gives the intended logical evolution through up to two physical faults at unknown times whenever every accumulated Pauli error remains of weight at most two, followed by ideal recovery.

The classes have distinct bottom-block logical/stabilizer patterns. Their relative signs are positive, negative, positive and negative respectively; every normalized class has absolute coefficient sum one. Therefore

```math
\ell=d+4,\qquad
J(H_\alpha)=|a_0|+|a_1|+|a_2|+|b|
=\frac{4d^2+21d+8}{8}.
```

Scaling by $\Omega$ gives $\omega=|\Omega|$. The code is unchanged, so its known-product-unitary syndrome reversibility distance remains infinite.

## 5. Optimality for arbitrary Hamiltonians on this family

The odd logical-coset weights and the need for three contributing weight sectors give $\ell\ge d+4$ for two-error transparency, as established in the [available-weight argument](https://github.com/GoGoKo699/Error-Transparent-Locality/blob/main/science/locality.md#5-available-weights-can-strengthen-the-bound). Thus (G6) attains minimum interaction order.

At that order, classify every native Pauli with nontrivial logical compression by its bottom-block factors. A full normalizer must normalize the inner five-qubit code in every block. Its induced logical label on the $B$ bottom blocks is a nontrivial logical Pauli of the depth-$(m-1)$ code. That induced word has odd weight at least $k$. If its weight were at least $k+2$, its physical weight would be at least $3k+6=d+6$, exceeding the allowed order. Its induced weight is therefore exactly $k$.

Each active factor has physical weight three or five; each inactive factor is identity or a weight-four inner stabilizer. At total weight at most $d+4$, only the four patterns used above remain. Their total weights $W$ and sums $R$ of squared bottom-block weights are

| Pattern | $W$ | $R$ |
|---|---:|---:|
| All $k$ active factors have weight three | $d$ | $3d$ |
| One active factor has weight five | $d+2$ | $3d+16$ |
| Two active factors have weight five | $d+4$ | $3d+32$ |
| One inactive factor is a weight-four stabilizer | $d+4$ | $3d+16$ |

Let $A=[h_L]_0$ and let $C_0,C_1,C_2,C_F$ be the scalar-free logical compressions of the Hamiltonian terms in these patterns. The normalization, first and second global Pauli-weight moments, and the sum of squared bottom-block weight superoperators yield

```math
\begin{pmatrix}
1&1&1&1\\
d&d+2&d+4&d+4\\
d^2&(d+2)^2&(d+4)^2&(d+4)^2\\
3d&3d+16&3d+32&3d+16
\end{pmatrix}
\begin{pmatrix}C_0\\C_1\\C_2\\C_F\end{pmatrix}
=\begin{pmatrix}A\\0\\0\\0\end{pmatrix}.
\qquad\text{(G7)}
```

For the fourth row, define $\mathcal W_b=\sum_{i\in b}(\mathrm{Id}-\mathcal R_i)$ in each bottom block. Every Pauli is an eigenoperator with eigenvalue its block weight. The map $\sum_b\mathcal W_b^2$ is a linear combination of conjugations by errors of weight at most two with coefficients summing to zero. Transparency therefore makes its scalar-free compression vanish. This proof also allows consistent scalar sector shifts. Detectable Paulis remain detectable under Pauli conjugation, and stabilizers remain scalar after compression, so neither contributes to (G7). No separate error-sector preservation is required of the four sub-Hamiltonians.

The matrix in (G7) has determinant $-256$. Its unique solution is

```math
(C_0,C_1,C_2,C_F)=(a_0,a_1,a_2,b)A.
```

If $J_j$ is the absolute native coefficient sum of pattern $j$, the compressed nontrivial logical Paulis each have norm one, so $J_j\ge\|C_j\|_\infty$. For one encoded qubit, $\|A\|_\infty=\omega$. The patterns are disjoint, and any additional scalar or detectable terms add nonnegative budget. Hence

```math
\boxed{J\ge\sum_j\|C_j\|_\infty
=J_*(d)\omega.}
```

This establishes the claimed optimality for arbitrary Hermitian Hamiltonians obeying the fixed-code full transparency assumptions, including consistent scalar error-sector shifts. It is a code-family statement, not a bound for arbitrary codes with the same distance and readout invariant.

An exact scalar dual certificate for the four rows of (G7) is

```math
y=\left(J_*(d),-d-3,\frac12,\frac18\right).
```

It evaluates to $(+1,-1,+1,-1)$ on the four columns and has right-hand-side value $J_*(d)$. The scalar total-weight relaxation instead gives $(4d^2+16d+8)/8$; the block refinement raises the lower bound by $5d/8$. The difference is the unavoidable negative stabilizer-padding contribution sharing weight $d+4$ with a positive two-promotion contribution.

## 6. Description size and scope

The theorem constructs finite positive signed-coset averages and a strict Hamiltonian at every depth. The direct expansion remains large. If $a_m=10^{(d-1)/2}$ is the number of minimum-weight logical representatives, the four dense support counts per axis are

```math
a_m,\qquad
\frac d5a_m,\qquad
\frac{d(d-3)}{50}a_m,\qquad
15(B-k)a_m.
```

The frontier-padding probabilities are generally nonuniform across the last class. Each inactive bottom block belongs to exactly one frontier subtree, so every word counted there receives positive mass. These dense counts are not lower bounds on necessary native term count.

A nonnegative support-reduction argument gives a separate existence guarantee. The number of protected physical Pauli errors, including identity, is

```math
D_2(n)=1+3n+9\binom n2.
```

Use one exact response equation for each of these errors, nonnegative absolute coefficients, and the four prescribed class signs. The dense construction is feasible. Reducing dependent positive support columns leaves at most $D_2(n)=O(n^2)$ native terms per logical axis. The moment equations force the same class masses for every feasible solution, so the exact coupling optimum survives this reduction. Integer response entries and an independent support give rational coefficients with polynomial bit length, for example $O(D_2(n)\log D_2(n))$ by Cramer's rule and the Hadamard bound. The depth-two [2,575-term certificate](two_error_gates.md#an-exact-sparse-representation) is a separate explicit instance.

### A theoretical polynomial-time synthesis procedure

The exponential candidate list can also be avoided in principle. Maintain a separate positive normalized Pauli distribution for each of $A_0,A_1,A_2,F$ and each logical axis. Preserve its complete response vector

```math
\bigl(\mathbb E[\chi(E,Q)]\bigr)_{\operatorname{wt}(E)\le2}
\in\mathbb Q^{D_2(n)}.
```

Conic support reduction within one class retains at most $D_2(n)$ positive words and preserves normalization, signed logical membership and every error-image response. The base at depth two is the four explicitly defined dense normalized classes; each can be reduced separately. Arbitrary class pieces extracted from a final sparse Hamiltonian must not be substituted unless their individual response vectors are checked.

For a parent with $k=3k'$ active bottom blocks, the dense class recurrences use the following mixtures over the ten outer minimum representatives and their three active child blocks:

| Parent class | Child-class mixture |
|---|---|
| $A_0$ | Three $A_0$ children |
| $A_1$ | One uniformly chosen active child uses $A_1$; the other two use $A_0$ |
| $A_2$ | With probability $(k'-1)/(3k'-1)$, one uniformly chosen child uses $A_2$; otherwise, with probability $2k'/(3k'-1)$, two uniformly chosen children use $A_1$. Remaining active children use $A_0$ |
| $F$ | With probability $3(k'-1)/(k-1)$, one uniformly chosen active child uses $F$. With probability $2/(k-1)$, choose an inactive root child uniformly and place $K_4$ in a uniformly chosen bottom block inside it. Other active children use $A_0$ |

The last row counts descendant frontiers and the two frontiers at the root separately. Localized $K_4$ padding in an inactive child has an explicit distribution on $15\cdot5^{m-2}=O(n)$ words. Every parent mixture involves at most four nonidentity child factors. Replacing each child distribution by its response-preserving sparse version preserves the parent's entire response vector: a physical error of total weight at most two restricts to errors of weight at most two in each child, Pauli conjugation signs factor across child blocks, and each product uses independent child distributions. No preservation of an auxiliary hidden support-tree distribution is required.

The sparse child lists have $O(n^2)$ words each. Thus a deliberately loose bound of $O(n^8)$ candidates suffices for each parent class before exact support reduction. The number of mixture types is constant, and only four classes for each of three axes are maintained at each level. The displayed response formulas have a common denominator dividing the safe polynomial bound $450B^2k(k-1)$. Since the response columns are integer sign vectors, independent-support coefficients have $O(n^2\log n)$ bits by Cramer's rule. Exact dependence elimination on these polynomial-size lists has polynomial bit complexity, including intermediate arithmetic. After constructing the four sparse classes, mix them with (G6) and reduce the resulting at most $4D_2(n)$ signed columns to at most $D_2(n)$ native terms. The moment proof again preserves the optimal budget.

This gives a theoretical polynomial-time synthesis procedure at arbitrary depth, with a high polynomial degree. A general implementation or practical runtime bound is not supplied by the current verification programs. Those programs certify the response identities, hierarchy correlations and finite instances; they do not claim to execute this sparse synthesis procedure at large depth.

All three Pauli axes have the same construction. Real linear combinations retain strict transparency and give continuous control of one encoded qubit, with the displayed axis combination costing $J_*(d)\sum_\alpha|\Omega_\alpha|$. The optimum relative to logical half-splitting is attained separately for the Pauli axes. Entangling logical gates, geometric locality, many-body synthesis, noisy recovery and a joint gate/readout threshold remain outside this resource model.

The code can correct more than two physical errors at larger depths, but the stated gate guarantee is fixed at $t=2$. The retained $r_S=\infty$ property concerns recovery after full ideal original-syndrome measurement for each specified known product unitary. It does not by itself compose that noise model with faults during a gate. Finite exact response and moment checks support the construction; the all-depth and all-Hamiltonian conclusions follow from the proofs above.
